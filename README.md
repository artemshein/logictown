# Тихий город — дом Леи

Браузерная 3D-игра на TypeScript, Babylon.js и Vite. Шесть помещений соединены открытыми проходами: спальня, гостиная, кухня, ванная, туалет и коридор. Перспективная камера держится за спиной Леи и плавно поворачивается вместе с ней. Перекрывающие её стены скрываются вместе с отделкой.

## Запуск

```powershell
npm ci
npm run dev
```

Открыть http://localhost:5173. Для смартфона в той же Wi-Fi-сети использовать Network URL Vite. Компьютер и сервер должны быть включены.

```powershell
npm run build
npm run preview
```

## Управление и история

Удерживайте кнопки справа: ↑/↓ — идти вперёд/назад, ↶/↷ — поворачивать Лею. На компьютере доступны WASD и стрелки. Можно одновременно идти и поворачивать. Значки предметов появляются только в текущей комнате в пределах 1,5 метра от места взаимодействия и в поле зрения камеры. Нажмите значок, чтобы исследовать предмет. В диалогах управление движением отключено; крестик или Escape закрывают диалог. Меню комнат и декоративных панелей нет.

Головоломка «Дом помнит» начинается с записки на столе в спальне или шкафчика в коридоре. Пять задач дают медальоны: весы на кухне, переливание воды в ванной, зеркальная коробочка, фотоальбом в гостиной и театр теней в спальне. Три фрагмента фотографии находятся в спальне, кухне и ванной. Подсказки с найденных медальонов можно перечитать в шкафчике.

Правильный порядок медальонов открывает ящик с ключом. Входная дверь находится в правом конце коридора. Лея выходит на небольшое крыльцо; можно вернуться в дом. Состояние задач, найденные фрагменты, медальоны и ключ сохраняются локально в `logictown-memory-v1`; текущая комната — отдельно. Старое сохранение раннего прототипа не удаляется.

## Персонаж и графика

Лея создана в Blender по концепту Б, модель: `public/models/lea-b.glb`. Просмотр персонажа: `/character.html`. Исходник, текстуры и проверки: `art/lea/model/`. Генератор: `scripts/build_lea.py`. Для игры Blender не нужен.

Мебель и отделка создаются в коде. Используются текстуры, тени, SSAO и постобработка. Производительность на реальном смартфоне пока не измерена. Это WebGL-прототип без PWA и офлайн-кэша; после выхода доступно только небольшое крыльцо, город ещё не построен.

## Проверки

Требуется Node.js 24:

```powershell
node scripts/check-house.mjs
node scripts/check-occlusion.mjs
node scripts/check-movement.mjs
node scripts/check-memory.mjs
npm run build
```

Проверяются связность проходов и новых точек взаимодействия, стены и мебель, скрытие стен, полная цепочка задач, неверные ответы, зависимость театра от фотографии, сохранение, все достижимые состояния кувшинов и единственность финального порядка.

Для ручной проверки через Vite доступны `/checks/memory.html` (интерфейсы всех задач) и `/checks/house.html` (3D-выход у двери). Они используют отдельное тестовое сохранение, не входят в производственную сборку и не выдают ключ в основной игре. Сначала нужно пройти задачи на странице проверки. В основной игре и тестовых страницах проверены диалоги, получение медальонов, сохранение ключа и выход.
