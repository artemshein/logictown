# Тихий город — дом Леи

Игровой 3D-прототип на TypeScript, Babylon.js и Vite. Дом состоит из шести помещений: комната Леи, гостиная, кухня, ванная, отдельный туалет и коридор. Мебель и отделка создаются геометрией в коде, персонаж загружается из GLB.

Лея по выбранному концепту Б теперь создаётся в Blender и экспортируется в `public/models/lea-b.glb`. Отдельный просмотр: `/character.html`. Исходник и сведения о проверке: `art/lea/model/README.md`. Для повторной генерации используется `scripts/build_lea.py`; Blender для обычного запуска игры не нужен.

Вторая графическая итерация (`src/art.ts`): мебель с фасками, отдельные деревянные доски, процедурные текстуры ткани и обоев, драпированное одеяло, шторы, листья с прожилками, детали лица и одежды, контактные тени, SSAO и постобработка. Эти эффекты увеличивают нагрузку на GPU; производительность на реальном смартфоне пока не измерена.

## Запуск

```powershell
npm install
npm run dev
```

Открыть http://localhost:5173. Для телефона в той же Wi-Fi-сети использовать Network URL, который напечатает Vite. Компьютер должен быть включён, сервер запущен, а локальное соединение доступно через брандмауэр.

```powershell
npm run build
npm run preview
```

## Управление

- Нажатие на пол задаёт путь. Персонаж обходит мебель по навигационной сетке.
- Значки над столом, шкатулкой и растением запускают взаимодействие после подхода.
- Записка объясняет головоломку. В шкатулке фигурки переключаются нажатием.
- Решение: луна, солнце, цветок. Награда — звезда и открытая шкатулка.
- Кнопка ♪ включает синтезированные звуки. Кнопка ? открывает помощь и сброс прогресса.
- Дом — единый этаж с открытыми проёмами. Нажатие на пол или название комнаты задаёт пеший маршрут через коридор; камера плавно следует за Леей. В новых комнатах есть мебель и предметы для исследования.
- Прогресс головоломки и текущая комната сохраняются локально. Escape закрывает диалоги.

## Границы прототипа

Один дом с шестью помещениями, один персонаж, одна головоломка в комнате Леи. Новые помещения пока предназначены для исследования. Это браузерный прототип без установки PWA и офлайн-кэша. Графика использует WebGL; реальная скорость на смартфонах требует проверки на устройствах. Шрифты Google Fonts необязательны: без сети используются системные аналоги.

## Проверка

Сборка TypeScript/Vite; ручное прохождение через браузер: подход к записке, переход к шкатулке, неверный ответ, верный ответ, получение награды, восстановление прогресса после перезагрузки. Адаптивный интерфейс проверяется отдельно на узком экране.

Проверка доступности всех дверей и взаимодействий по навигационной сетке: `node scripts/check-house.mjs` (Node.js 24). Непрерывный маршрут из коридора в ванную и следование камеры проверены в браузере. Тест проверяет связность всех помещений, открытые пороги, стены, мебель и внешние границы.


Планировка и общая навигационная сетка: `src/layout.ts`. Все комнаты загружаются при старте; переходы не скрывают комнаты и не перемещают персонажа мгновенно.

Стены и их отделка автоматически скрываются, когда перекрывают Лею со стороны камеры, и возвращаются после её ухода. Проверка геометрии обзора: `node scripts/check-occlusion.mjs`.
