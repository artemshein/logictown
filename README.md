# Тихий город — дом Леи

Браузерная 3D-игра на TypeScript, Babylon.js и Vite. Шесть помещений соединены открытыми проходами: спальня, гостиная, кухня, ванная, туалет и коридор. Перспективная камера держится за спиной Леи и плавно поворачивается вместе с ней. Стены полные и постоянные; камера сокращает расстояние до Леи перед стеной, не проходя сквозь неё.

## Запуск

```powershell
npm ci
npm run dev
```

Открыть http://localhost:5173. Для смартфона в той же Wi-Fi-сети использовать Network URL Vite. Компьютер и сервер должны быть включены.

```powershell
npm run build
npm run preview
```

## Управление и история

Удерживайте кнопки справа: ↑/↓ — идти вперёд/назад, ↶/↷ — поворачивать Лею. На компьютере доступны WASD и стрелки. Можно одновременно идти и поворачивать. Значки предметов отрисовываются как объекты внутри 3D-канваса, перекрываются стенами и мебелью и появляются только в текущей комнате в пределах 1,5 метра от места взаимодействия и в поле зрения камеры. Нажмите значок, чтобы исследовать предмет. В диалогах управление движением отключено; крестик или Escape закрывают диалог. Меню комнат и декоративных панелей нет.

Головоломка «Дом помнит» начинается с записки на столе в спальне или шкафчика в коридоре. Пять задач дают медальоны: весы на кухне, переливание воды в ванной, зеркальная коробочка, фотоальбом в гостиной и театр теней в спальне. Три фрагмента фотографии находятся в спальне, кухне и ванной. Подсказки с найденных медальонов можно перечитать в шкафчике.

Правильный порядок медальонов открывает ящик с ключом. Входная дверь находится в правом конце коридора. Лея выходит на небольшое крыльцо; можно вернуться в дом. Состояние задач, найденные фрагменты, медальоны и ключ сохраняются локально в `logictown-memory-v1`; текущая комната — отдельно. Старое сохранение раннего прототипа не удаляется.

## Персонаж и графика

В игре используется модель [Cute Chibi Girl — Free Game-Ready Character](https://sketchfab.com/3d-models/cute-chibi-girl-free-game-ready-character-28e2f98ab4bf4313a3f258d45d987716) автора Yury Misiyuk, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Игровой файл: `public/models/cute-chibi-girl.glb`. Он подготовлен из скачанного GLB скриптом `scripts/prepare-chibi.mjs`: исправлена упаковка ключей анимации без изменения геометрии и текстуры. Масштаб настроен в игре, ходьба добавлена программно, две позы используются для действий. Исходная модель Леи по концепту Б сохранена в `art/lea/model/` и `public/models/lea-b.glb`, но больше не используется в игре. Просмотр нового персонажа: `/character.html`.

Основная мебель загружается из 12 моделей Poly Haven (CC0): кровать с текстилем, диван, кресло, столы, стулья, шкафы, корзина, лампа и растения. Шесть наборов материалов используются для штукатурки, паркета, дерева, ткани и плитки. Модели загружаются по комнатам и переиспользуются; исходная геометрия служит запасным вариантом при ошибке загрузки. Холодильник, ванна и унитаз — готовые CC0-модели 3DAssets.dev; источники, лицензии и пометка автора об AI-генерации сохранены в `public/assets/fixtures/credits.json`. Обои и настенная плитка используют прежнюю отделку комнат, чтобы библиотечная штукатурка не перекрывала рисунок. Планировка, раковины и механизмы головоломок пока остаются процедурными. Источники и авторы перечислены в `public/assets/polyhaven/credits.json`. Используются текстуры, тени, SSAO и постобработка. Производительность на реальном смартфоне пока не измерена. Это WebGL-прототип без PWA и офлайн-кэша; после выхода доступно только небольшое крыльцо, город ещё не построен.

## Проверки

Требуется Node.js 24:

```powershell
node scripts/check-dog.mjs
node scripts/check-interior.mjs
node scripts/check-house.mjs
node scripts/check-camera.mjs
node scripts/check-movement.mjs
node scripts/check-memory.mjs
npm run build
```

Проверяются связность проходов и новых точек взаимодействия, стены и мебель, столкновения камеры и её проход через открытые проёмы, полная цепочка задач, неверные ответы, зависимость театра от фотографии, сохранение, все достижимые состояния кувшинов и единственность финального порядка.

Для ручной проверки через Vite доступны `/checks/memory.html` (интерфейсы всех задач) и `/checks/house.html` (3D-выход у двери). Они используют отдельное тестовое сохранение, не входят в производственную сборку и не выдают ключ в основной игре. Сначала нужно пройти задачи на странице проверки. В основной игре и тестовых страницах проверены диалоги, получение медальонов, сохранение ключа и выход.

## Обновление библиотечных ассетов

`node scripts/fetch-interior.mjs` скачивает исходные glTF и материалы 1K из публичного API Poly Haven в игнорируемый `.asset-cache`. Затем Blender запускает `scripts/prepare-interior.py`: нормализует опорную точку и ограничивает геометрию до 16 тысяч треугольников на модель (растение — 12 тысяч). `node scripts/compress-interior.mjs` сжимает встроенные непрозрачные карты JPEG без уменьшения разрешения, сохраняя прозрачность листвы. В игру входят автономные GLB и локальные карты — доступ к Poly Haven во время игры не нужен.

Проверка всех комнат доступна в режиме разработки: `/checks/interior.html`. Эта страница не входит в сборку и использует отдельное тестовое сохранение.

## Щенок-компаньон

Небольшой сиба-ину из [Ultimate Animated Animals](https://quaternius.com/packs/ultimateanimatedanimals.html) автора Quaternius / Tomás Laulhé, CC0. Модель содержит 1950 треугольников и занимает около 503 КБ; оставлены анимации ходьбы и покоя. Посадка плавно задаётся на исходном скелете. Щенок следует по свободным клеткам дома, обходит мебель и садится сбоку от остановившейся Леи.

У каждого ещё не собранного фрагмента фотографии щенок лает один раз за текущий запуск игры. Учитывается комната обоих персонажей, поэтому подсказка не срабатывает через стену. Звук разблокируется первым нажатием или касанием; кнопка ♪ справа вверху отключает звук. Лай — один обрезанный звук из [Dog Barking (mono)](https://opengameart.org/content/dog-barking-mono), Brandon Morris / HaelDB, CC0. Источники и изменения перечислены в `public/models/dog/credits.json`, оригинальная лицензия модели — в `public/models/dog/LICENSE.txt`.

`node scripts/check-dog.mjs` проверяет обход препятствий, все комнаты, крыльцо, остановку рядом с Леей, одно срабатывание на фрагмент, собранные фрагменты, отключённый звук и валидность GLB. В режиме разработки `/checks/dog.html` позволяет пройти к трём фрагментам и увидеть число срабатываний; `/checks/dog-pose.html` показывает посадку крупно. Страницы не входят в производственную сборку.
