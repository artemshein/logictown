# Лея Б — первый объёмный эскиз

## Файлы

- `lea-b.blend` — редактируемый исходник Blender 5.2.1: игровая сетка, текстуры, арматура, четыре клипа и студия для рендера.
- `../../../public/models/lea-b.glb` — игровой GLB с текстурами и анимациями.
- `lea-b-render.png` — рендер реальной модели в Blender, не генерация изображения.
- `stats.json` — статистика экспорта.
- `validation.json` — отчёт Khronos glTF Validator.
- `check-*.png` — проверка поз анимации в Blender.

## Просмотр

`npm run dev`, затем http://localhost:5173/character.html — вращение, приближение, четыре анимации и просмотр лица. http://localhost:5173/ — та же модель подключена к комнате, передвижению и взаимодействиям. При ошибке загрузки сохраняется прежний персонаж и появляется сообщение.

## Повторная генерация

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python scripts/build_lea.py
node scripts/validate-lea.mjs
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python scripts/render_lea_checks.py
npm run build
```

Генератор перезаписывает текущие результаты в этой папке и GLB в `public/models`. Перед ручными правками сохраняйте отдельную версию `.blend`.

## Статус и ограничения

- Создана настоящая текстурированная 3D-сетка со скелетной деформацией: около 32 тысяч треугольников, 17 костей, 15 материалов.
- Именованные клипы: Idle, Walk, Interact, Celebrate. Лицевой риг, моргание и полноценная мимика пока отсутствуют.
- Геометрия создана программно в Blender. Это первый объёмный эскиз по концепту Б, а не точное воспроизведение качества исходной иллюстрации. Лицо, линия роста волос, кисти, посадка одежды и движения требуют художественной доработки.
- GLB проверен Khronos glTF Validator. Скрипт дополнительно проверяет наличие skin weights, скелета и четырёх клипов.
- Анимационные позы проверены реальными рендерами Blender. TypeScript/Vite собирается.
- Визуальная проверка в браузере в этом проходе не выполнена: инструмент браузера отклонил открытие страницы политикой URL. Производительность на телефоне не измерена.
- Blender установлен через winget, пакет BlenderFoundation.Blender 5.2.1, официальный MSI download.blender.org.
